Give tools distinct purposes, narrow schemas, explicit side effects, examples, and retry-aware errors. Distribute only needed capabilities and choose built-in, custom, or MCP interfaces according to ownership and reuse.

Practice turning an ambiguous tool set into an interface Claude can select safely.
