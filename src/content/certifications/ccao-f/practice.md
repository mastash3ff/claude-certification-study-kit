Use public or synthetic information only. The evidence matters more than a polished artifact.

## 1. Brief, draft, and validate

- Choose a real communication task and write a complete brief with audience, sources, constraints, and format.
- Generate a first draft, identify one factual and one audience-fit risk, and revise with targeted feedback.
- Verify every material claim against the supplied sources.

Evidence: the original brief, annotated first draft, source check, and final audience-ready version.

## 2. Build a maintained Project

- Configure a Project with purpose, source boundaries, output conventions, and escalation rules.
- Add a small curated knowledge set containing one deliberately superseded document.
- Test whether users can distinguish current, absent, and conflicting evidence.

Evidence: an ownership and refresh note plus three test conversations.

## 3. Integrate a bounded workflow

- Map a current process and identify one drafting, analysis, or organization step Claude can augment.
- Define baseline time, quality criteria, review owner, and a rollback point.
- Pilot the step on representative cases and record benefits and misses.

Evidence: before/after process maps and a measured recommendation to expand, revise, or stop.

## 4. Governance and troubleshooting tabletop

- Run scenarios involving sensitive data, fabricated citations, biased wording, stale knowledge, and an unapproved connector.
- For each, name the first evidence to inspect, the accountable owner, immediate containment, and durable correction.

Evidence: a one-page decision table that distinguishes prompt fixes, configuration fixes, policy escalation, and human review.
