# Security policy

## Reporting a vulnerability

Do not open a public issue for a vulnerability that could put users at risk. Use GitHub's private vulnerability reporting feature for this repository. If that feature is unavailable, contact the maintainer privately through the contact method on their GitHub profile.

Include the affected route or component, reproduction steps, impact, and any suggested mitigation. Avoid including real credentials or personal data.

This is a static, client-side application. Study progress is stored in browser local storage and is never submitted to this project.
